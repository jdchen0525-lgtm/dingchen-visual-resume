# 江定承｜影像創作者履歷

個人履歷與作品集網站，內容包含個人資料、工作經歷、攝影作品集，以及三支短影音剪輯作品與剪輯工作區視覺。

## 網站內容

- 個人履歷與聯絡方式
- JDD FILM 攝影作品集
- 三支直式短影音作品
- 響應式手機與電腦版面
- 素材箱、監看器、效果控制與多軌時間軸介面

## 本機啟動

請先安裝 Node.js 22 以上版本。

```bash
npm install
npm run dev
```

啟動後依終端機顯示的網址開啟網站。

## 建置

```bash
npm run build
```

## 主要頁面

- `/`：個人履歷
- `/works`：攝影與短影音作品集
